# Draft implementation decisions

1. **Local only.** PRD sections 19–21 take precedence over earlier hero, cloud and auth suggestions. Nothing was published. The supplied document remains product reference material, not workspace agent instructions.
2. **Local database.** The current workspace uses an isolated MongoDB replica set on port 27018, using the installed MongoDB Server 9.0 executable and workspace-owned data files. The existing standalone server on port 27017 is not reconfigured. Existing JSON data is copied into MongoDB in one transaction, preserving record IDs and retaining the original JSON file. A clean checkout can still use the one-process JSON development driver.
3. **React 19.2.** The PRD suggests React 18. FLOWSTACK 0.3.0 supports React >=18, but its published collection types include React 19 nodes. React and its types were aligned at 19.2 instead of applying unsafe component casts.
4. **No invented official tariff.** Sample round-number tariff rates are marked illustrative, with no claim that they are the current MERC schedule. Capacity defaults and generation estimates are likewise unverified. The government scheme page supports the seeded central subsidy amounts; scheme approval is still external.
5. **Conservative physical limits.** Both scenarios respect roof space and sanctioned load. A tolerance never creates extra physical space or silently increases approved electrical load. Planned EV/AC load is explanatory only. This adds a sanctioned-load safety constraint to the PRD's consumption-cap pseudocode.
6. **Economics limits.** Net cost cannot be negative. A zero quote remains zero. Fixed charges remain after net energy falls to zero. Payback is null when it is not reached. The 25-year figure subtracts upfront cost and the configured replacement event. Banking runs through an illustrative Jan–Dec year; no tariff inflation, loan model or unstated maintenance charge is invented.
7. **One reviewable snapshot.** Rules, tariff, scheme and district yield travel together through the review workflow. Each saved result retains its full snapshot and version IDs. A draft based on a superseded snapshot cannot publish. Future-dated activation is refused until its effective date; scheduling is deferred.
8. **No false measured savings.** A recorded bill minus a model using that same bill's consumption is a cost variance, not a counterfactual no-solar baseline. The bills page labels it accordingly. True before/after savings is deferred until baseline data exists.
9. **Local auth.** OTP codes are random six-digit values; only HMAC digests are persisted. Local codes are deliberately visible in development. Refresh tokens are stored as hashes; access tokens stay in memory. Local staff numbers are synthetic seed fixtures. Production boot is explicitly refused.
10. **Development film.** The generator renders a deterministic skyline to 40 WebP frames for each aspect ratio. The manifest is replaceable with a finished film sequence. The first frame displays without waiting for the sequence. Reduced motion uses a dawn poster.
11. **Draft scope.** Working calculator/account/bill/review workflows were prioritised. Deferred PRD pages and integrations are identified in README; they are not represented as complete.
